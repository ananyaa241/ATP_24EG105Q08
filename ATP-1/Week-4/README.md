#  ATP Week 4: HTML & CSS Mastery

##  Overview
Welcome to Week 4 of the ATP course! This week advances your HTML and CSS skills through practical layout techniques, forms, and component design. You'll explore responsive layouts, CSS Grid and Flexbox, styled forms, tables, and reusable UI components.

##  What You Will Learn
- HTML structure for forms, tables, and cards
-  CSS layout with Grid and Flexbox
-  Styling reusable UI components
-  Building responsive page projects
-  Organizing styles for clean visual design

##  How to Use This Folder
1. Open the `Week-4` folder in your code editor.
2. Preview each HTML file in the browser to see layouts and designs.
3. Compare HTML structure with CSS rules to understand styling effects.
4. Modify examples or create variants to practice layout and styling.

##  Recommended Learning Flow
1. **Start Here**: `EX-1.html`, `EX-2.html`, `EX-3.html` - Review basics
2. **Forms**: `forms/form.html` - Form structure and input styling
3. **Grid Layout**: `grid container/Ex-7.html` - CSS Grid patterns
4. **Projects**: `project-1`, `project-2`, `project-3` - Complete page examples
5. **Components**: `table/EX-4.html`, `user-card/usercard.html` - Component styling

##  Tips for Improvement
-  Experiment with responsive widths and grid columns
-  Add hover and focus states to form fields and buttons
-  Try converting projects to mobile-first layouts
-  Combine Grid and Flexbox for complex layouts
