# URL Reference Guide

Use this guide to keep track of URLs during deployment.

---

## 📝 URLs to Fill In During Deployment

### Step 1: Deploy Backend on Render

**Your Render Backend URL will be generated automatically**

Example format: `https://sample-project-backend.onrender.com`

When deployment completes, you'll see:
```
✓ Your service is live at: https://YOUR_SERVICE_NAME.onrender.com
```

**Copy this URL and save it!** You'll need it for steps 2 and 3.

---

### Step 2: Deploy Frontend on Vercel

**Before deploying, update `frontend/.env.production`:**

```
VITE_API_BASE_URL=https://YOUR_RENDER_BACKEND_URL
```

Replace `YOUR_RENDER_BACKEND_URL` with the URL from Step 1.

**Example:**
```
VITE_API_BASE_URL=https://sample-project-backend.onrender.com
```

**Your Vercel Frontend URL will be generated automatically**

Example format: `https://your-app.vercel.app`

When deployment completes, Vercel shows:
```
✓ Production: https://your-app.vercel.app
```

**Copy this URL and save it!** You'll need it for step 3.

---

### Step 3: Update Backend CORS on Render

**Go back to Render and update the backend FRONTEND_URL environment variable:**

```
FRONTEND_URL=https://YOUR_VERCEL_FRONTEND_URL
```

Replace `YOUR_VERCEL_FRONTEND_URL` with the URL from Step 2.

**Example:**
```
FRONTEND_URL=https://your-app.vercel.app
```

Click Save → Render will auto-redeploy in ~2 minutes

---

## 📊 Complete URL Mapping

After deployment, your URLs will look like this:

| Service | URL | Environment Variable | Where Set |
|---------|-----|---------------------|-----------|
| **Render Backend** | https://your-backend.onrender.com | N/A | Auto-generated by Render |
| **Vercel Frontend** | https://your-app.vercel.app | N/A | Auto-generated by Vercel |
| **Frontend Uses** | (backend URL) | `VITE_API_BASE_URL` | Vercel Environment Variables |
| **Backend Uses** | (frontend URL) | `FRONTEND_URL` | Render Environment Variables |

## ⚠️ Important Notes

### Case Sensitivity
- URLs are case-sensitive
- `https://MyApp.vercel.app` ≠ `https://myapp.vercel.app`

### Exact Match Required
- FRONTEND_URL in Render must **exactly match** Vercel URL
- VITE_API_BASE_URL in Vercel must **exactly match** Render URL

### No Trailing Slashes
- Use: `https://your-app.vercel.app`
- Not: `https://your-app.vercel.app/`

### Protocol Required
- Use: `https://` (not `http://`)
- Vercel and Render use HTTPS for production

## 🐛 Debugging URLs

If you get CORS errors or 404s, check:

1. **CORS Error in browser console?**
   - Go to Render → Check FRONTEND_URL
   - Make sure it exactly matches your Vercel URL
   - Wait 2 minutes for redeploy

2. **API 404 Error?**
   - Open browser DevTools → Network tab
   - Look at the API request URL
   - Should be: `https://your-backend.onrender.com/emp-api/employees`
   - If not, check VITE_API_BASE_URL in Vercel

3. **Blank page?**
   - Browser console for JavaScript errors
   - Network tab to see API responses
   - Check URLs are correct in environment variables
